# SWOT-анализ бренда работодателя Level Group

**Курсовой проект** | НИУ ВШЭ, Высшая школа бизнеса  
**Направление:** 38.03.05 «Бизнес-информатика»  
**Год:** 2025  
**Команда:** Арустамян Микаэл Артурович, Раднаев Артур Владимирович, Измоденов Иван Игоревич, Багишев Артём Валерьевич, Сорокин Иван Игоревич

---

## О проекте

Комплексный анализ бренда работодателя девелоперской компании **Level Group** —
одного из топ-3 застройщиков жилой недвижимости Москвы.

Цель — разработать стратегии продвижения HR-бренда среди профессионалов
и специалистов строительной отрасли на основе SWOT-анализа.

---

## Методология

| Инструмент | Применение |
|---|---|
| PESTEL-анализ | Макросреда: политика, экономика, технологии, ESG |
| Модель 5 сил Портера | Конкурентная среда на рынке труда |
| Анализ КФУ | Сравнение Level Group с 5 конкурентами (ПИК, Самолёт, ФСК, Донстрой, Инград) |
| SWOT (первичный) | Сильные/слабые стороны, возможности, угрозы |
| Поэлементный SWOT | SO / WO / ST / WT — матрица стратегических альтернатив |

---

## Ключевые выводы

- **Кадровый дефицит** в строительстве составляет 200–400 тыс. чел. по России;
  в Москве спрос на специалистов вырос на 47% за 2024 год
- Текучесть кадров в отрасли — **72,2%** (2-е место среди всех отраслей по Росстату)
- Level Group занимает **3-е место** по корпоративной культуре среди крупных
  московских девелоперов, но уступает конкурентам по уровню зарплат

## Стратегические рекомендации

### 1. TikTok / SMM-кампания для HR-бренда
- Контент-форматы: «день из жизни», закулисье стройки, истории стажёров
- Целевая аудитория: студенты и молодые специалисты (18–29 лет)
- KPI: охват, вовлечённость, конверсия в отклики на вакансии

### 2. Кейс-чемпионаты и хакатоны
- Форматы заданий: BIM-проектирование, IT/разработка, финансовая аналитика, HR-стратегии
- Партнёрство с вузами (ВШЭ, профильные технические университеты)
- KPI: 10–20% финалистов → в HR-воронку

### 3. Позиционирование через AI-технологии
- Генеративный дизайн, цифровые двойники, BIM+AI
- Референсы: Skanska (Safety Sidekick), Balfour Beatty (StoaOne AI)
- Цель: привлечение IT- и BIM-специалистов, усиление имиджа tech-работодателя
